== About this volume

The Tebako Volume collects, in one reading order, the normative
specifications of the tebako packaging ecosystem and the composition
calculus that states their model formally. It exists to be cited: each
chapter is one specification, carrying the same TBK SPEC number, the same
section numbering, and the same text as the standalone series rendering
and as the Markdown source of truth in the product repository. A reference
of the form "TBK SPEC 02 §1" resolves identically against all three.

The reading order is the order an implementer meets the machinery. The
series landing and the system overview set the vocabulary. The wire format
and the payload manifest define what a package is. The store, the jail,
and the registry and trust specifications define how packages are cached,
confined, and believed. The virtual filesystem, the driver contract, and
the launcher ABI define how a run composes. The operational specifications
— observability, distribution, audit, transparency, and solving — close
the series, and the composition calculus states the whole as one small
formal system.

The volume is built by the ecosystem's own toolchain: the packed metanorma
payload, installed from the official tebako registry, compiles this
document, and the PDF is an artifact of every docs publish of tebako.org.
The provenance of the build you are reading — source revisions, toolchain
versions, artifact checksums — is recorded in the colophon.
